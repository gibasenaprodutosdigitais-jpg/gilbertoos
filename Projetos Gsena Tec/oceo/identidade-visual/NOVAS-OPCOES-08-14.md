# OCEO — novas opções de marca (08–14)

7 opções a mais, na mesma linguagem do set 01–07 (traço navy `#17335c` +
acento dourado `#dd9a34`, viewBox 200×200). Cada uma tem versão **cor** e
**mono**. Preview: `_novas-preview.png`. Gerador: `gerar-novas.py`.

Referência: OCEO é um **SaaS completo de gestão para empresas** (ERP + BI),
que unifica **5 pilares** (GC contábil/BI, GF financeiro, GJ jurídico, GM
marketing/vendas, GI educação pré-investimento) — princípio "o sistema
orienta, você decide". O nome lê como **"O CEO"**.

| # | Nome | Ideia (ligada ao business plan) |
|---|---|---|
| 08 | **BI / painel** | O anel com 3 barras crescentes — o produto é ERP **+ BI**, dashboard, crescimento. |
| 09 | **Órbita** | O anel com um ponto dourado orbitando — ciclo de gestão, o sistema em movimento ao redor do negócio. |
| 10 | **5 pilares** | O formado por 5 arcos — os **5 pilares** como um sistema só; o arco dourado é a frente ativa. |
| 11 | **Medidor** | Velocímetro com ponteiro — controle, performance, "medir para decidir". |
| 12 | **Monograma O·C** | O externo + um C interno — **"O CEO"**: transformar o empreendedor em gestor. |
| 13 | **Estrela-norte** | Anel + estrela de 4 pontas — "o sistema **orienta**", o norte da decisão. |
| 14 | **Pedra-chave** | Anel aberto no topo com a cunha dourada encaixada — a peça que **trava a estrutura** do negócio. |

Arquivos: `logo-08-bi.svg` / `logo-08-bi-mono.svg` … até `logo-14-chave`.
